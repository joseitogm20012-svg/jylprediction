# Frontend Design Workflow

## Instrucciones del Flujo
1. Antes de escribir código CSS o HTML, define por escrito:
   - Paleta cromática exacta (Hex/Tailwind).
   - Escala de tipografías y pesos.
   - Intención y curvas de animaciones.
2. Evita patrones genéricos de IA (sombras exageradas y tarjetas blancas simples).
3. Adapta el diseño a la semántica nativa del framework utilizado.
